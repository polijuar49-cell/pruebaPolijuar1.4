# Polijuar Descartables — Frontend React

## Requisitos
- Node.js 18+

## Instalación

```bash
cd polijuar-frontend
npm install
npm run dev
```

Abrí el navegador en: **http://localhost:5173**

> ⚠️ El backend FastAPI debe estar corriendo en `http://localhost:8000`

## Funcionalidades
- Listado de productos con paginación
- Búsqueda por nombre o código
- Filtro por categoría
- Filtro de activos/inactivos
- Crear producto
- Editar producto
- Activar / desactivar (baja lógica)
- Eliminar producto (con confirmación)
